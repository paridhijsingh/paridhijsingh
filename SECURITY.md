# Security policy

This repository is a personal GitHub profile README. It does not ship application code, process user data, or run production services.

## Supported versions

| Version | Supported |
| --- | --- |
| `main` (latest profile README) | Yes |
| Historical commits and forks | No |

## Reporting a vulnerability

**Do not** file a public GitHub issue for security concerns.

If you find exposed secrets, a malicious link in this README, account impersonation, or another security issue connected to this profile, email **paridhijaysingh@gmail.com** with:

- A short description of the issue
- The affected URL or file path
- Steps to reproduce, if applicable
- Whether you plan to disclose it publicly and on what timeline

You can also use [GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) if it is enabled on this repository.

## Response timeline

- Acknowledgement within **7 days**
- Status update within **14 days**
- Fix or documented decision within **30 days** for issues in this repository (for example, removing a leaked token or a harmful link)

If the report is out of scope (for example, a vulnerability in a different repository or a third-party widget host), you will be pointed to the right owner when possible.
